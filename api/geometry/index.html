    steercert.geometry¶

    Write-side geometry: the effect Gramian and certificates built from it.

    Every function here operates on NumPy arrays and needs no deep-learning framework. Model instrumentation lives in :mod:steercert.hf.

    Notation

    gradients has shape (n_examples, width). Row i is the derivative of a scalar behavioural functional phi_i with respect to the activation at one intervention site. directions has shape (n_directions, width); rows are normalised internally, so only their orientation matters.

    The effect Gramian is W = E[g g^T]. It is never formed as a dense width x width matrix: all spectral quantities come from a thin SVD of the gradient matrix.

    EffectGeometry dataclass ¶

    Spectral summary of the effect Gramian W = E[g g^T].

    Attributes:

    Name Type Description
    trace float

    tr(W), the mean squared gradient norm.
    leading_eigenvalue float

    lambda_max(W); sqrt of it is the RMS effect of the best direction.
    stable_rank float

    tr(W) / lambda_max(W). Near 1, per-example gradients are nearly collinear and sign-randomised controls become degenerate.
    participation_ratio float

    tr(W)^2 / ||W||_F^2.
    entropy_effective_rank float

    exp of the Shannon entropy of the normalised spectrum.
    entropy_rank_over_width float

    Effective rank divided by the activation width.
    mean_gradient_norm float

    ||g_bar||, the absolute signed write leverage. Report it next to every relative efficiency.
    top_eigenvalues tuple[float, ...]

    Leading eigenvalues of W.
    top_direction ndarray

    Leading eigenvector of W, the RMS-optimal write direction.

    to_dict() ¶

    JSON-serialisable summary (the direction is omitted).

    unit(vector, eps=EPS) ¶

    Return a unit-norm copy of vector.

    Raises:

    Type Description
    ValueError

    If the vector is zero or not finite, because its direction is undefined.

    cosine_abs(left, right, eps=EPS) ¶

    Absolute cosine between two vectors, or 0.0 if either is null.

    project_orthogonal(vector, normal) ¶

    Project vector onto the orthogonal complement of normal.

    mean_gradient(gradients) ¶

    Mean behavioural gradient g_bar; its norm is the absolute write leverage.

    rho(gradients, probe) ¶

    Alignment |cos(probe, g_bar)| between a read direction and the mean gradient.

    rho = 1 means the probe points exactly where a signed write is most effective; rho = 0 means writing along the probe has no first-order mean effect.

    effect_geometry(gradients, top_k=10) ¶

    Compute the effect-Gramian spectrum and rank diagnostics.

    The leading direction is the first right singular vector of the gradient matrix, oriented so that it has a non-negative inner product with the mean gradient.

    certificate_scores(gradients, directions) ¶

    First-order write certificates for each candidate direction.

    Returns:

    Type Description
    signed, mean_absolute, rms:

    |E[g^T w]|, E[|g^T w|] and sqrt(E[(g^T w)^2]) for every unit-normalised row w of directions. The signed score predicts the mean effect of a small step; the other two keep per-example effects that cancel in the mean.

    signed_dark_direction(gradients, probe) ¶

    Best signed-effect direction constrained to be orthogonal to probe.

    This is (I - p p^T) g_bar normalised: a direction the probe cannot see that still moves the behaviour on average.

    rms_dark_direction(gradients, probe) ¶

    Best RMS-effect direction constrained to be orthogonal to probe.

    Solves the Rayleigh problem for P W P with P = I - p p^T through the SVD of the projected gradients.

    subspace_dark_direction(gradients, read_basis) ¶

    Best RMS-effect direction orthogonal to a whole read subspace.

    Parameters:

    Name Type Description Default
    read_basis ndarray

    Array of shape (k, width) whose rows span the subspace a monitor reads (for example several probes, or SAE features used for detection).

    		 required

    usable_radius(gradients, direction, curvature) ¶

    Step size up to which the first-order certificate is trustworthy.

    For a unit direction with signed certificate s and a bound M on the directional second derivative, the linear term dominates the quadratic remainder while alpha < 2 s / M.

    second_order_prediction(alpha, first_directional, second_directional) ¶

    Second-order Taylor prediction alpha * d1 + alpha^2 / 2 * d2 per example.

    stacked_mean_gradient_direction(gradient_blocks) ¶

    Optimal unit-energy direction for writing at several sites at once.

    Each block has shape (n_examples, width_at_site) and rows must refer to the same examples. The result concatenates the per-site mean gradients and normalises them under one total-energy constraint.
