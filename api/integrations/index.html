    Integrations¶

    Converters between steercert and other interpretability and steering libraries.

    Each submodule imports its target library lazily, so import steercert never requires them. Install the extras you need, for example pip install steercert[steering-vectors].

    Layer convention: every library here indexes by decoder block output, which is :meth:steercert.hf.Site.block.

    as_site_vectors(vectors) ¶

    Normalise {layer_index or Site: vector} into {Site: float64 array}.

    Interoperate with steering-vectors <https://github.com/steering-vectors/steering-vectors>_.

    SteeringVector.layer_activations maps a decoder-block index to a vector that is added to that block's output at every selected token, so audit it with positions="all" unless you restrict token_indices to the last token.

    from_steering_vector(steering_vector) ¶

    Extract {Site.block(k): vector} from a steering_vectors.SteeringVector.

    to_steering_vector(vectors, dtype=None) ¶

    Build a SteeringVector from block-output directions, e.g. a dark direction.

    Interoperate with repeng <https://github.com/vgel/repeng>_ control vectors.

    ControlVector.directions maps a layer id to a vector that ControlModel adds to the output of decoder block layer_id at every position. repeng reads its training activations from hidden_states[layer_id + 1], which is the same tensor except for the last block, where Hugging Face applies the final norm first.

    from_control_vector(control_vector) ¶

    Extract {Site.block(k): vector} from a repeng.ControlVector.

    to_control_vector(vectors, model_type) ¶

    Build a repeng.ControlVector from block-output directions.

    Export to and import from lm-evaluation-harness steering configs.

    lm-eval-harness evaluates a steered model with::

    lm_eval run --model steered \
    --model_args pretrained=EleutherAI/pythia-160m,steer_path=steer.pt \
    --tasks hellaswag

    steer.pt maps a hookpoint (a module name relative to model.base_model) to a dict with steering_vector, steering_coefficient, action, bias and head_index. With action="add" the vector is added to that module's output at every position, so the matching certificate uses positions="all".

    Typical use: pick directions with :func:steercert.audit (for example a dark direction or the Gramian-top direction), export them here, and measure their capability cost on standard benchmarks.

    to_steer_config(model, vectors, coefficient=1.0, normalise=True) ¶

    Build an lm-eval steer_path dictionary for model.

    With normalise=True each vector is scaled to unit norm, so coefficient is the step size in activation units. Use :func:steercert.hf.residual_norm_median to choose a comparable value.

    save_steer_config(path, model, vectors, coefficient=1.0, normalise=True) ¶

    Write :func:to_steer_config to path with torch.save.

    load_steer_config(path, model) ¶

    Read a .pt steer config and map hookpoints back to sites.

    Returns {site: (vector, coefficient, action)} so existing configs, including ones derived from SAE features, can be audited.

    Collect certificate gradients through nnsight <https://nnsight.net>_.

    With remote=True the same code runs on the National Deep Inference Fabric (NDIF), which serves open models up to hundreds of billions of parameters. That makes certificates on 8B-405B models possible without a local GPU.

    Status: experimental. Verified locally with nnsight 0.7 on small models, where gradients and states match :func:steercert.hf.collect to 1e-6; remote execution depends on NDIF's deployed models and its policy for gradients and custom code, which can change. Validate a remote result against a local run on a small model first.

    Example

    from nnsight import LanguageModel # TransformersModel on nnsight >= 0.8 from steercert.hf import token_ids, token_logit_difference from steercert.integrations.nnsight import collect_nnsight model = LanguageModel("meta-llama/Llama-3.1-8B") phi = token_logit_difference(token_ids(model.tokenizer, ["hate"]), token_ids(model.tokenizer, ["love"])) data = collect_nnsight(model, prompts, layers=[8, 16, 24], functional=phi, remote=True)

    collect_nnsight(model, prompts, layers, functional, *, remote=False, batch_size=8, max_length=128) ¶

    Last-token states and per-example gradients at the outputs of layers.

    model is an nnsight.LanguageModel (TransformersModel on nnsight >= 0.8) or any nnsight.NNsight wrapper with a tokenizer. Results are keyed by :meth:steercert.hf.Site.block and feed straight into :func:steercert.audit.
